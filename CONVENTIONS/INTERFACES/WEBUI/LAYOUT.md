# Web UI layout
> Load when: laying out a web page or arranging its header, navigation and content.

- Center a one-line `h1` at up to 3.3rem, scale it to fit 320px without wrapping, omit the hero and tagline, add a `❯` prompt and a 3–4px accent top rule; put the byline in the footer.
- Order the navbar as title, non-empty "Compatible with" carousel, full-width tabs, then filter.
- Keep folder tabs and filter in a sticky toolbar.
- Use collapsible nested groups with counts and a category index; show the index as a sidebar when wide and a disclosure when narrow.
- At 360px, prevent horizontal page scroll; contain wide tables and code in their own scrolling boxes.
