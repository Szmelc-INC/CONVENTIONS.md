# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The community is expected to be welcoming and respectful, and harassment, discrimination, personal attacks, and other harmful conduct are not acceptable.

## Reporting and enforcement

Report conduct concerns to the project maintainer, [@sernik77](https://github.com/sernik77). Do not post sensitive details in a public issue or Discussion. If the concern involves the maintainer, report it through [GitHub Support](https://support.github.com/contact/report-abuse). The maintainer will review reports promptly, protect reporter confidentiality where possible, and may issue a warning, remove content, restrict participation, or ban an account. Enforcement decisions should be proportionate to the conduct and applied consistently.

The maintainer is responsible for enforcing this policy. If a report concerns the maintainer, use GitHub's [report abuse](https://support.github.com/contact/report-abuse) route.

This policy applies in project spaces and when someone is publicly representing the project.
