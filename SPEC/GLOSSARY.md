# Glossary

- **Rule:** A Markdown instruction file with a title, trigger, stable ID, and optional metadata.
- **Trigger:** The `Load when` hint or expression that tells a consumer when to load a rule.
- **Core:** A top-level collection of related rules and supporting files.
- **Pack:** A distributable, named collection of rules or Skills.
- **Profile:** Project identity and presentation values applied during rendering.
- **Overlay:** A higher-precedence configuration layer that changes profile values or disables rules.
- **Adapter:** A compiler that maps rules to a host's native instruction format.
