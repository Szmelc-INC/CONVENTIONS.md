# Decision 0001: publish Format 1.0 under MIT

- Status: accepted
- Date: 2026-11-26
- Proposal: define a portable, versioned format for agent convention collections.
- Decision: publish the prose, schemas, fixtures, and examples under the repository MIT license.
- Rationale: adopters can copy and adapt format text and examples without adding a second license boundary.
- Alternatives: CC BY 4.0 for prose was considered and rejected to keep the collection under one license.
- Compatibility: no effect on repository release versioning or host-specific adapter behavior.
